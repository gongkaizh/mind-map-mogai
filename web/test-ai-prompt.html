🤖 AI提示词优化对比

📋 优化概述

主要改进点：

  • 路径连贯性强化：明确要求与整体路径保持连贯性及逐层细化深入
  • 结构化分析：将提示词分为"结构分析"和"核心要求"两大部分
  • 四维度要求：路径连贯性、父子关联性、同级协调性、内容规范
  • 逻辑链条完整：强调从根节点到当前节点的逻辑链条要完整
  • 专业化表述：使用更专业、更精确的AI指令语言

🔄 提示词对比

优化前

我正在创建一个思维导图，需要你帮我扩展其中的一个分支。具体情况如下： 1. 当前路径：项目管理 -> 风险管理 -> 风险识别 2. 同级主题：风险评估、风险应对 3. 续写要求： - 这是第3层节点的展开 - 需要与父主题"风险管理"保持密切关联 - 考虑与同级主题的关联性和互补性 - 展开的内容要简洁、重点突出 - 每个分支的层级不要超过2层 - 每个节点的描述要简短，通常不超过10个字 请帮我继续展开主题"风险识别"的下级内容，要求内容准确、逻辑清晰、结构合理。

优化后

我正在创建一个思维导图，需要你帮我扩展其中的一个分支。请仔细分析整体结构和上下文关系： 【思维导图结构分析】 1. 完整路径：项目管理 → 风险管理 → 风险识别 2. 当前层级：第3层 3. 同级主题：风险评估、风险应对 【核心要求】 1. 路径连贯性： - 必须与所属的整体路径保持连贯性及逐层细化深入 - 每一层的展开都要承接上一层的逻辑，形成清晰的递进关系 - 从根节点"项目管理"到当前节点"风险识别"的逻辑链条要完整 2. 父子关联性： - 生成的子节点必须与直接父主题"风险识别"保持密切关联 - 不能偏离父主题的核心含义和范围 - 要体现对父主题的具体化、细分化或深入化 3. 同级协调性： - 考虑与同级主题"风险评估、风险应对"的关联性和互补性 - 避免与同级主题重复或冲突 - 保持同级主题间的逻辑平衡 4. 内容规范： - 每个节点描述简洁明确，通常不超过8个字 - 展开层级控制在1-2层，避免过度展开 - 内容要准确、专业、有实用价值 - 结构要清晰，便于理解和记忆 请基于以上要求，为主题"风险识别"生成合适的下级内容，确保与整个思维导图的逻辑体系高度一致。

🎯 测试场景

场景1：深层路径测试

企业管理 → 人力资源 → 招聘管理 → 面试流程 → 技术面试

测试重点：验证AI是否能理解5层深度的路径关系，生成的内容是否与"企业管理"的整体目标保持一致。

场景2：复杂同级关系测试

产品开发 → 用户体验 → 交互设计

同级主题：视觉设计、信息架构、可用性测试

测试重点：验证AI是否能避免与同级主题重复，保持互补性。

场景3：专业领域测试

医疗健康 → 临床诊断 → 影像诊断 → CT检查

测试重点：验证AI在专业领域是否能保持术语准确性和逻辑严谨性。

🚀 使用指南

  1. 打开思维导图应用：http://localhost:8080
  2. 创建一个多层级的思维导图结构
  3. 选择某个节点，右键选择"AI续写"
  4. 观察生成的提示词是否包含了优化后的结构
  5. 测试AI生成的内容是否符合路径连贯性要求
  6. 验证生成内容与父主题和同级主题的关联性
