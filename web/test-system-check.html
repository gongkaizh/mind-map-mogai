思维导图体系化检查功能测试

测试说明

本页面用于测试思维导图体系化检查功能。该功能已经实现并集成到主应用中。

如何测试：

  1. 打开主应用：http://localhost:8080
  2. 创建或导入一个思维导图
  3. 在工具栏中找到"体系化检查"按钮（图标为检测图标）
  4. 点击按钮查看分析结果

功能特性 已实现

  • 多维度评分系统（结构完整性、逻辑连贯性、层级合理性、内容丰富度、结构平衡性）
  • 100分制评分，自动计算总分和各项详细评分
  • 问题识别和分类（错误、警告、提示三个级别）
  • 具体问题路径定位
  • 智能改进建议生成
  • 美观的对话框界面展示结果
  • 工具栏集成，一键触发检查

检查维度说明

1. 结构完整性检查

检查思维导图的基本结构是否完整：

  • 空节点检测：发现内容为空的节点
  • 单子节点检测：发现只有一个子节点的父节点
评分影响：空节点每个扣10分（最多扣30分），单子节点每个扣5分（最多扣20分）

2. 逻辑连贯性检查

检查同级节点之间的逻辑关联性：

  • 同级节点相关性分析
  • 内容连贯性评估
评分影响：发现不连贯的同级节点组合时扣分

3. 层级合理性检查

检查思维导图的层级结构是否合理：

  • 深度检查：层级过深（超过6层）会被标记
  • 平衡检查：各分支深度差异过大会被标记
评分影响：层级过深扣20分，深度不均扣15分

4. 内容丰富度检查

检查节点内容的丰富程度：

  • 短内容节点统计（少于3个字符）
  • 内容质量评估
评分影响：超过70%的节点内容过短时扣25分

5. 结构平衡性检查

检查各主要分支的平衡程度：

  • 分支节点数量分析
  • 结构对称性评估
评分影响：分支间节点数量差异过大时扣15分

评分等级说明

  • 90-100分：优秀 - 思维导图结构完整，逻辑清晰
  • 80-89分：良好 - 整体结构较好，有少量改进空间
  • 70-79分：一般 - 基本结构合理，需要一些优化
  • 60-69分：较差 - 存在明显问题，需要重点改进
  • 60分以下：很差 - 结构存在严重问题，建议重新组织

测试建议

为了充分测试功能，建议创建以下类型的思维导图：

  1. 完美结构：层级合理、内容丰富、逻辑清晰的思维导图
  2. 有空节点：包含一些空白节点的思维导图
  3. 层级过深：超过6层深度的思维导图
  4. 内容简短：大部分节点内容很短的思维导图
  5. 结构不平衡：各分支节点数量差异很大的思维导图
